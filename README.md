# Alerta Criminal

Um aplicativo de segurança comunitária e denúncia de incidentes em tempo real com mapas, planejamento de rotas seguras e gamificação.

## Funcionalidades
- **Mapa em Tempo Real:** Veja e reporte incidentes na sua região.
- **Grupos Privados:** Crie redes de segurança para bairros ou condomínios.
- **Painel Admin:** Moderação de relatos e visualização de viaturas.
- **Feedbacks:** Envie sugestões e acompanhe as respostas da equipe.
- **PWA:** Instalável diretamente no seu dispositivo.

## Stack
- React + Vite
- Tailwind CSS
- Firebase (Auth, Firestore, Storage)

## Como rodar localmente
1. Instale as dependências com `npm install`
2. Inicie o servidor de desenvolvimento com `npm run dev`
